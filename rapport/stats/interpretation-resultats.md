## 0. Message-clé (à poser en tête de section et à tenir)

- **Résultat principal, neutre : aucune des trois mesures n'est significative** à n = 8
  (p bi = .250 / .312 / .469). On ne peut **ni** conclure à un effet, **ni** à son absence (sous-puissance).
- Les tailles d'effet vont dans le sens prédit (modérées à grandes), mais **à n = 8 une taille
  d'effet est elle-même très instable** (intervalle de confiance large ; r_rb tend à sur-estimer ;
  les seuils de Cohen sont des repères, pas des preuves). → parler de **tendances suggestives**, pas d'effets établis.
- **Un motif observé, à présenter comme hypothèse exploratoire et NON comme résultat** : les
  contre-sens se concentrent chez les lecteurs chevronnés (P04, P07, P08 ; + P03), qui sont aussi
  le pôle (-) de l'entretien. C'est cohérent **mais** : (a) c'est un sous-groupage **post-hoc** sur
  4 personnes par cellule, non testé ; (b) le confond ordre/difficulté joue **dans les deux sens**
  (cf. §5) ; (c) la convergence quali peut refléter une **désirabilité sociale** (le testeur a conçu
  l'outil). → à formuler comme piste à confirmer, jamais comme « la quanti est en fait positive ».
- **Lecture honnête à n = 8** : taille d'effet + slope plot + compte k/8 en appui, **mais bornés
  par la non-significativité et par l'absence de contrebalancement**. Le p reste l'indicateur sobre.

## 1. NASA-RTLX : charge cognitive (figures : `slope_rtlx.png`, `tlx_subscales.png`)

**Chiffres.** AVEC Mdn = 33,3 (IQR 24,6) ; SANS Mdn = 54,2 (IQR 27,1) ; W = 9 ; p uni = .125 ;
p bi = .250 ; r_rb = -.50 (grand) ; dz = -.44 ; **6/8** dans le sens prédit. Contre-sens : **P04, P08**.

- **C'est la mesure la mieux orientée des trois** (plus grand r_rb), mais **non significative**
  (p = .125 uni, .250 bi) : tendance suggestive, pas baisse établie.
- **Slope plot** : 6 pentes descendent (SANS → AVEC), souvent fortes (P05 -50, P06 -45, P01 -33).
  Les 2 qui montent (P04, P08) sont **lisibles à l'œil** = à pointer honnêtement, sans les écarter.
- **Sous-dimensions** (`tlx_subscales.png`, médianes SANS → AVEC) :
  - **Mentale 75 → 35** = la plus grosse chute. **C'est le cœur du claim** : l'artefact décharge
    le « quelles notes jouer ? ». À mettre en avant.
  - **Effort 70 → 50** = reste la dimension la plus haute AVEC. Bon angle : l'outil **ne joue pas
    à la place**, il reste exigeant → contre l'objection « béquille qui fait tout » (relie T10).
  - **Temporelle 47,5 → 25** : baisse aussi au médian. Donc le **plafond « lumières trop vite »
    n'apparaît pas au niveau du groupe** ; il est **individuel** (morceaux rapides / P04 Coltrane changes).
    À croiser avec T7 (lisibilité, vitesse/turnarounds) plutôt que de le généraliser.
  - Physique / Perf / Frustration : toutes plus basses AVEC, cohérentes.
- **Frustration ↓** = pont vers le STAI-6 (triangulation §5).

> **[APA]** En condition AVEC, la charge perçue (RTLX) était plus faible (Mdn = 33,3 ; IQR = 24,6)
> qu'en condition SANS (Mdn = 54,2 ; IQR = 27,1). Le test de Wilcoxon des rangs signés (exact,
> unilatéral) ne révèle pas de différence significative (W = 9, p = .125), mais la taille d'effet
> est grande et dans le sens attendu (r_rb = -.50 ; dz = -.44 ; 6/8 paires) [voir Fig. slope RTLX].

## 2. STAI-6 : anxiété-état (figure : `slope_stai6.png`)

**Chiffres.** AVEC Mdn = 33,3 (IQR 16,7) ; SANS Mdn = 46,7 (IQR 25,0) ; W = 10 ; p uni = .156 ;
p bi = .312 ; r_rb = -.44 (moyen) ; dz = -.47 ; **5/8** dans le sens prédit. Contre-sens : **P04, P07, P08**.

- Effet **moyen**, sens prédit (moins anxieux AVEC). Dispersion AVEC plus resserrée (IQR 16,7 vs 25,0)
  → l'aide **uniformise vers le bas** l'anxiété pour la majorité.
- **Slope plot** : les fortes baisses (P03 -30, P01 -37, P06 -37, P05 -30) viennent des
  participants **les plus anxieux SANS** → c'est là que le filet agit le plus (relie T4, verbatim
  P06 « un filet qui est là »).
- Les 3 contre-sens (P04, P07, P08) sont **modestes** (P07/P08 = +6,7 chacun) sauf P04 (+30) ;
  ce sont les chevronnés pour qui « zone de confort = grille connue » (verbatim P07 « plus en
  sécurité sans… surpris de le dire »).

> **[APA]** L'anxiété-état (STAI-6) tendait à être plus basse AVEC (Mdn = 33,3 ; IQR = 16,7) que
> SANS (Mdn = 46,7 ; IQR = 25,0), sans atteindre le seuil de significativité (W = 10, p = .156),
> avec un effet moyen dans le sens prédit (r_rb = -.44 ; 5/8). Au vu de n = 8, ce résultat est
> indicatif et sous-puissant pour conclure.

## 3. SELFEFF : auto-efficacité / confiance (figure : `slope_selfeff.png`)

**Chiffres.** AVEC Mdn = 4,2 (IQR 3,4) ; SANS Mdn = 4,4 (IQR 1,6) ; W = 9 ; p uni = .234 ;
p bi = .469 ; r_rb = +.36 (moyen) ; dz = +.23 ; **4/7** (P03 = différence nulle, exclu).
Contre-sens : **P04, P07, P08**.

- **La mesure la plus faible (p bi = .469) et la plus polarisée.** Les médianes sont quasi
  identiques (4,2 vs 4,4). Deux lectures possibles, **à présenter toutes deux** : (a) effet nul /
  bruit sur 8 personnes ; (b) la médiane plate recouvre deux faisceaux qui se croisent dans le slope
  plot (certains montent, d'autres descendent). Le slope plot **suggère** (b), il ne le démontre pas.
- **IQR plus grand AVEC (3,4 vs 1,6)** = la dispersion **augmente** : hausses (P01 +2,5 ; P06 +3,75 ;
  P05 +2,5) et baisses (P04 -2 ; P08 -1,75 ; P07 -1,25) coexistent. Compatible avec un **modérateur
  de niveau**, mais cette interaction n'est **pas testée** (n trop petit) → hypothèse, pas résultat.
- **P03 (nul, exclu)** : pianiste classique qui ne lit pas le chiffrage, plancher à 2,25 des deux
  côtés → à signaler comme cas particulier (n effectif = 7).
- Penser à **valider avec l'item 11** (confiance globale 0-10, mesure de contrôle) si tu l'as saisi.

> **[APA]** Aucune différence significative n'a été détectée pour l'auto-efficacité (Mdn AVEC = 4,2 ;
> Mdn SANS = 4,4 ; W = 9, p = .234), bien que la tendance aille dans le sens attendu (r_rb = +.36,
> effet moyen ; 4/7 paires, une différence nulle exclue). La quasi-identité des médianes masque une
> forte polarisation selon le niveau (cf. slope plot), discutée en §5.

## 4b. Entretien superviseur (expert) : évaluation pédagogique (§5a, descriptif)

> Source : `matrice-entretien-superviseur.md`. Rester descriptif ; la triangulation avec le
> quanti et les participants va en §5. Dans le rapport, cet entretien expert est la sous-section
> **§5a** (avant les tendances participants §5b). **Statut : avis d'un seul expert** (le
> professeur de jazz) → validation de cadrage, pas une donnée mesurée ; risque de désirabilité
> (il assiste à la démo et dialogue avec le concepteur).

- **Valide le cadrage « charge cognitive » (3 extraits, accord explicite).** Le professeur
  formule de lui-même le mécanisme visé : « suivre la couleur » dispense du monologue intérieur
  (« il ne faut pas qu'ils se parlent trop quand ils jouent », « on peut juste jouer, puis se
  taire ») ; il confirme en séance que « se trop parler / trop réfléchir » = charge cognitive.
  → l'orientation QR1 (réduire la charge mentale) est **endossée par l'expert**. **Convergence
  de construit**, pas preuve de l'effet mesuré.
- **Public cible « réglable » (Public Cible).** Débutant→intermédiaire est le bon point
  d'entrée ; le système est extensible vers le haut (gammes de substitution sur les dominantes).
  → cadre le périmètre de l'étude **et** anticipe l'axe niveau (cf. §5, modérateur post-hoc).
- **Légitimité pédagogique (Pédagogie Alternative, 2 extraits).** Il inscrit l'artefact dans les
  pédagogies alternatives (Suzuki, « mettre le focus sur un paramètre et le faire faire
  beaucoup »), le qualifie de « pédagogie avant-garde », et fait l'hypothèse que l'oreille et la
  mémoire musculaire se forment même sans calcul de gamme. Bon pour la conclusion (vision
  pédagogique, pas gadget). **Mais** c'est une hypothèse d'expert, **pas un transfert mesuré**
  (relie la limite T8, rétention faible).
- **Contre-risque assumé : surcharge, pas seulement décharge (Feedback, extrait 1).** « Les
  lumières, quand il y a de la grille, elles vont beaucoup trop vite », d'où sa proposition de
  « gammes passe-partout ». → l'expert pointe **lui-même** le risque que la densité d'affichage
  *ajoute* de la charge, à l'opposé de l'effet visé. **Converge** avec T7 (participants, « trop
  vite / turnarounds ») et le plafond Temporelle individuel (P04). Indice fort à porter en §5.
- **« Très serré » / temps humain (Feedback, extrait 2).** Inquiétude que les apprenants n'aient
  « pas le temps de capter » ; le système devrait suivre le rythme de l'utilisateur, pas
  l'inverse. → caveat d'interprétation : un **temps d'adaptation** propre à chacun existe et pèse
  sur la lecture des résultats (relie le confond + la mono-séance, §6).
- **Désétayage endossé (Feedback, extrait 3).** Il propose d'« éteindre la lumière » petit à
  petit, ou partiellement (n'éclairer que les cadences). → **converge** avec le consensus
  participant T10 (« petites roues à enlever »). L'outil est cadré, **des deux côtés**, comme une
  béquille à dépasser.

## 5. Triangulation et réponse aux QR (Discussion : ne PAS mettre en Résultats)

**Ce que la triangulation autorise (et ce qu'elle n'autorise pas).** Les trois mesures vont dans le
même sens (charge ↓, anxiété ↓, confiance ↑ AVEC) **et** le vécu en entretien va dans le même sens.
Cette convergence est **encourageante mais faible** : aucun test n'est significatif, et la convergence
peut être en partie un artefact (désirabilité sociale ; mêmes participants des deux côtés). À écrire
comme **faisceau d'indices cohérent**, pas comme preuve.

- **Motif observé : axe familiarité de la grille** (P05 le verbalise, « gestion de l'inhabituel »,
  [16:04]) : débutants/interm. (P01, P02, P05, P06) plutôt favorables ; chevronnés (P04, P07, P08 ;
  + P03) plutôt à contre-sens, quanti **et** quali. **Mais c'est un sous-groupage post-hoc (4 vs 4),
  hypothèse-génératrice, non testé** → à proposer pour de futures études, pas à conclure ici.
- **Pourquoi p n'est pas significatif : par construction à n = 8.** Le plancher de puissance est tel
  qu'une poignée de paires à contre-sens suffit. **Ne pas en faire** « l'effet est réel, ce sont les
  experts qui le cachent » : ce serait écarter sélectivement les données qui dérangent. La lecture
  sobre est : **échantillon trop petit et trop hétérogène pour trancher.**
- **Le confond ordre / nouveauté / difficulté joue dans LES DEUX SENS.** Pour P04/P08, AVEC = 1er
  tour + morceau le plus dur (26-2/Coltrane, Giant Steps) → leur contre-sens est **plausiblement dû
  au confond, pas au dispositif**. Mais **symétriquement**, on ne peut pas garantir que les baisses
  des débutants ne tiennent pas, elles aussi, à *quel morceau* est tombé en AVEC. Le confond
  **fragilise tout le monde**, pas seulement les contre-sens. (Cas le moins confondu : **P05**, qui
  va dans le sens prédit *malgré* AVEC = 1er tour.)
- **Plafond d'utilisabilité — convergence à trois sources** : Temporelle ↓ au groupe, mais ↑ sur
  morceau rapide (P04) ; T7 participants « trop vite / turnarounds » ; **et l'expert** (« les
  lumières vont beaucoup trop vite », d'où sa piste « gammes passe-partout », cf. §4b). Trois
  angles indépendants pointent la même saturation de lisibilité sur grilles rapides. **Indice
  convergent fort**, pas démonstration (1 cas quanti).
- **L'expert valide le mécanisme QR1 mais nomme aussi le contre-risque** : il endosse la décharge
  (« suivre la couleur » → « se taire ») **et** la surcharge possible (densité d'affichage). La
  charge nette dépend donc du dosage (vitesse, densité, choix du morceau, temps d'adaptation,
  cf. §4b) → cohérent avec un effet RTLX réel mais **fragile et conditionnel**, pas garanti.
- **Liens inter-mesures** : STAI ↔ Frustration TLX (les deux ↓) et auto-efficacité ↔ T3 « j'ai osé »
  vont dans le sens prédit ; cohérent, non confirmatoire.
- **Réponses aux QR (à formuler prudemment)** :
  - **QR1 (charge)** : **indices convergents** d'une charge perçue plus basse AVEC (RTLX, Mentale
    75 → 35, T1, **+ cadrage validé par l'expert**, §4b), **non significatifs** et **nuancés** par
    l'écoute (T6), la vitesse (T7) et le contre-risque de surcharge que l'expert pointe lui-même.
  - **QR2 (oser / anxiété)** : **indices convergents** allant dans le sens d'une moindre anxiété et
    d'une confiance accrue (STAI, SELFEFF, T3/T4), **non significatifs**, **avec une hétérogénéité
    marquée selon le profil**. Conclure « rassure le public cible » serait prématuré : à poser comme
    **hypothèse pour une étude mieux contrôlée et plus puissante**.

## 6. Limites à écrire (honnêteté méthodo, §6.4 / conclusion)

- **Pas de contrebalancement morceau ↔ condition** : effet d'ordre et effet-morceau non neutralisés
  (confond maximal chez P04/P08), seulement atténués par le design intra-sujet apparié.
- **Hétérogénéité de niveau** non contrôlée = dilue le test (mais **révèle** le modérateur, valorisable).
- **Auto-efficacité ad hoc (non validée)** ; **STAI à chaud rétrospectif**.
- **Mono-séance, pas de mesure de transfert** (cf. T8 rétention faible).
